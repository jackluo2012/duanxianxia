## 功能概览

短线侠是一个专业的 A 股实时行情分析平台，提供以下核心功能：

| 功能模块 | 描述 | 访问路径 |
|---------|------|---------|
| **实时行情** | 实时股票行情、分时图、K线图 | `/` |
| **竞价分析** | 集合竞价数据分析、排行榜、告警 | `/auction` |
| **自选股管理** | 管理关注的股票列表 | `/auction` → 自选股 |
| **告警系统** | 自定义价格和成交量告警 | `/auction` → 告警配置 |

## 实时行情功能

### 1. 实时行情首页

访问路径：`http://localhost:5173/`

#### 主要功能

**实时数据展示**
- 每 3 秒自动更新股票行情
- 显示当前价格、涨跌幅、成交量
- 实时买一价、卖一价
- 分时图和 K 线图可视化

#### 分时图

**时间范围**: 交易时段 9:30-15:00

**数据刷新**: 每 3 秒

**图表特点**:
- 横轴：交易时间
- 纵轴：股票价格
- 蓝色曲线：价格走势
- 阴影区域：成交量

**使用方法**:
1. 在搜索框输入股票代码（如 `000001`）
2. 点击 "订阅" 按钮添加到监控列表
3. 分时图自动开始更新

#### K 线图

**支持周期**:
- 5 分钟 K 线
- 日 K 线

**图表元素**:
- 红色蜡烛：收盘价 > 开盘价（上涨）
- 绿色蜡烛：收盘价 < 开盘价（下跌）
- 上影线：最高价
- 下影线：最低价

**切换周期**:
1. 点击图表上方的周期切换按钮
2. 选择 "5分钟" 或 "日线"
3. 图表自动重新加载对应数据

### 2. 历史行情查询

#### API 使用

**查询历史分时数据**:
```bash
GET http://localhost:8083/api/quotes/000001/history?period=1m&start=2026-01-01&end=2026-01-03
```

**查询 K 线数据**:
```bash
GET http://localhost:8083/api/kline/000001?period=5m&limit=100
```

**参数说明**:
- `code`: 股票代码（6 位数字）
- `period`: 时间周期
  - `1m`: 1 分钟
  - `5m`: 5 分钟
  - `1d`: 日线
- `start`: 开始日期（格式：YYYY-MM-DD）
- `end`: 结束日期（格式：YYYY-MM-DD）
- `limit`: 返回记录数（默认 100）

### 3. 实时数据订阅

WebSocket 实时推送服务：

```javascript
// 连接 WebSocket
const ws = new WebSocket('ws://localhost:8080/ws/realtime');

// 订阅股票
ws.send(JSON.stringify({
  action: "subscribe",
  codes: ["000001", "600000", "000002"]
}));

// 取消订阅
ws.send(JSON.stringify({
  action: "unsubscribe",
  codes: ["000001"]
}));

// 接收实时数据
ws.onmessage = (event) => {
  const quote = JSON.parse(event.data);
  console.log('实时行情:', quote);
};
```

**数据格式**:
```json
{
  "code": "000001",
  "name": "平安银行",
  "price": 12.50,
  "preclose": 12.30,
  "change_percent": 1.63,
  "volume": 1234567,
  "datetime": "2026-01-04 09:30:00"
}
```

## 竞价分析功能

访问路径：`http://localhost:5173/auction`

### 1. 竞价时段

A 股集合竞价时间：
- **上午**: 9:15 - 9:25
- **下午**: 无（仅上午）

### 2. 竞价排行榜

提供 4 种排行榜类型：

#### 买封排行榜（买封）

**含义**: 买单封单金额最高的股票

**用途**: 发现市场主力资金流向

**更新频率**: 每 5 秒

**查看方法**:
1. 进入竞价分析页面
2. 点击 "买封排行" 标签
3. 默认显示前 20 名

#### 强度排行榜（强度）

**含义**: 抢筹强度评分最高的股票（0-100 分）

**评分因素**:
- 封单金额
- 价格涨幅
- 成交量
- 买卖盘比例

**查看方法**:
1. 点击 "强度排行" 标签
2. 按强度评分降序排列
3. 查看每只股票的详细评分

#### 涨幅排行榜（涨幅）

**含义**: 竞价涨幅最高的股票

**用途**: 发现当日热门股

**查看方法**:
1. 点击 "涨幅排行" 标签
2. 按涨幅百分比降序排列

#### 异动排行榜（异动）

**含义**: 价格波动最大的股票

**用途**: 发现异常波动的潜在机会

**查看方法**:
1. 点击 "异动排行" 标签
2. 按价格波动率降序排列

### 3. 竞价详情页面

**访问方法**: 点击排行榜中的任意股票

**显示内容**:
- 基本信息：代码、名称、当前价格
- 实时数据：价格、成交量、涨跌幅
- 封单信息：买封金额、卖封金额
- 强度评分：0-100 分的综合评分
- 竞价曲线图：价格和封单量走势

**竞价曲线图**:
- 横轴：竞价时间（9:15-9:25）
- 左纵轴：价格
- 右纵轴：封单金额
- 蓝色线：价格走势
- 柱状图：封单金额

### 4. 竞价告警功能

#### 创建告警规则

**路径**: 竞价分析 → 告警配置 → "新建告警"

**告警类型**:

1. **价格涨幅告警**
   - 条件：竞价涨幅 >= 阈值
   - 示例：涨幅 >= 5% 时告警

2. **封单金额告警**
   - 条件：买封金额 >= 阈值（万元）
   - 示例：封单 >= 1000 万元时告警

3. **强度评分告警**
   - 条件：强度评分 >= 阈值
   - 示例：强度 >= 80 分时告警

4. **异动检测告警**
   - 条件：价格波动率 >= 阈值
   - 示例：波动率 >= 3% 时告警

**创建步骤**:
1. 点击 "新建告警" 按钮
2. 选择告警类型
3. 设置阈值条件
4. 选择触发股票（全部或指定）
5. 点击 "保存" 创建告警

**告警限制**:
- 单个用户最多 20 条告警规则
- 同一股票 5 分钟内最多 3 次告警（防止告警风暴）

#### 查看告警历史

**路径**: 竞价分析 → 告警历史

**显示信息**:
- 告警时间
- 股票代码和名称
- 告警类型
- 触发值
- 告警规则

### 5. 自选股管理

#### 添加自选股

**方法 1: 从竞价排行榜添加**
1. 在排行榜中找到目标股票
2. 点击股票右侧的 "加自选" 按钮

**方法 2: 手动添加**
1. 进入 "自选股管理" 标签
2. 点击 "添加股票" 按钮
3. 输入股票代码（如 `000001`）
4. 点击 "确认"

**限制**: 每个用户最多 100 只自选股

#### 查看自选股

**路径**: 竞价分析 → 自选股管理

**显示信息**:
- 股票代码和名称
- 当前价格
- 涨跌幅
- 强度评分
- 添加时间

#### 删除自选股

**方法**: 在自选股列表中，点击股票右侧的 "删除" 按钮

## 常见问题

### Q1: 为什么看不到实时数据？

**原因**: 当前不在 A 股交易时段或竞价时段

**交易时段**:
- 上午：9:30 - 11:30
- 下午：13:00 - 15:00

**竞价时段**:
- 上午：9:15 - 9:25

**解决方案**:
- 在交易时段查看实时行情
- 在竞价时段查看竞价数据
- 或联系管理员启用测试模式（FORCE_MODE）

### Q2: 数据更新频率是多少？

**实时行情**:
- 交易时段：每 3 秒
- 盘后时段：每 5 分钟
- 节假日：暂停采集

**竞价数据**:
- 竞价时段：每 5 秒
- 非竞价时段：暂停采集

**排行榜**:
- 自动刷新：每 5 秒

### Q3: 为什么有些股票没有数据？

**可能原因**:
1. 股票代码不存在或已退市
2. 股票当日停牌
3. 数据源暂时中断
4. 网络连接问题

**解决方法**:
1. 验证股票代码是否正确（6 位数字）
2. 查看股票公告确认是否停牌
3. 刷新页面或重新订阅
4. 检查网络连接

### Q4: 告警为什么不触发？

**检查清单**:
1. 告警规则是否启用
2. 当前是否在竞价时段（9:15-9:25）
3. 阈值设置是否合理
4. 是否触发告警风暴保护（5 分钟最多 3 次）

**调试方法**:
1. 在告警历史中查看历史记录
2. 临时降低阈值测试
3. 查看浏览器控制台错误信息

### Q5: WebSocket 连接失败怎么办？

**症状**: 浏览器控制台显示 WebSocket 连接错误

**检查清单**:
1. 后端服务是否运行（`http://localhost:8080`）
2. 防火墙是否允许 WebSocket 连接
3. 网络代理是否拦截 WebSocket

**解决方法**:
1. 重启后端服务
2. 检查浏览器控制台详细错误
3. 尝试使用 HTTP 轮询模式（如支持）

### Q6: 如何提高竞价告警准确性？

**建议**:
1. **组合条件**: 同时设置价格涨幅和封单金额
2. **合理阈值**: 参考历史数据设置阈值
3. **过滤干扰**: 排除 ST 股、*ST 股
4. **关注持续性**: 优先选择持续高强度的股票

**示例配置**:
```
告警类型: 组合告警
条件1: 涨幅 >= 5% AND 封单金额 >= 1000万
条件2: 强度评分 >= 80
过滤: 排除 ST 股票
```

### Q7: 数据保存多长时间？

**当前版本**:
- 实时行情数据：ClickHouse 永久保存
- 竞价数据：ClickHouse 永久保存
- 告警历史：当前未设置过期时间

**未来计划**:
- 自动归档 6 个月以上数据
- 提供数据导出功能
- 用户自定义保留期限

## 最佳实践

### 1. 竞价分析策略

#### 强势股筛选

**步骤**:
1. 每日 9:15 前登录系统
2. 进入竞价分析 → 强度排行榜
3. 关注强度评分 >= 80 的股票
4. 查看竞价曲线，确认价格走势
5. 结合封单金额判断主力意图

**案例**:
```
目标: 发现当日强势股
方法:
1. 强度评分 >= 80
2. 买封金额 >= 1000万
3. 涨幅 >= 3%
4. 加入自选股监控
```

#### 异动股捕捉

**步骤**:
1. 每日 9:15-9:25 持续监控异动排行榜
2. 关注突然跳升的股票
3. 查看竞价详情，分析异动原因
4. 评估是否跟进

**注意事项**:
- 异动可能是噪声，需结合其他指标
- 关注量价配合
- 避免追高风险

### 2. 告警配置建议

#### 新手配置

**保守型**:
```
告警1: 涨幅 >= 8%（大幅上涨）
告警2: 封单金额 >= 5000万（大资金介入）
告警3: 强度评分 >= 90（非常强势）
```

**激进型**:
```
告警1: 涨幅 >= 3%（小幅上涨）
告警2: 封单金额 >= 500万（中等资金）
告警3: 强度评分 >= 70（较强）
```

#### 高级配置

**组合告警**:
```
告警规则: 涨幅 >= 5% AND 封单金额 >= 1000万
目的: 过滤虚假信号，提高准确性
```

**分时段配置**:
```
09:15-09:20: 关注高涨幅告警（试探性）
09:20-09:25: 关注高封单告警（确定性）
```

### 3. 自选股管理建议

**分类管理**:
- **核心关注**: 每日必看（5-10 只）
- **机会池**: 潜在机会（20-30 只）
- **观察区**: 长期跟踪（其余）

**定期清理**:
- 每周清理无效股票
- 删除长期无机会的股票
- 更新核心关注列表

### 4. 数据分析技巧

#### 使用历史数据回测

**步骤**:
1. 导出历史竞价数据
2. 分析强势股后续表现
3. 优化告警阈值
4. 验证策略有效性

#### 对比分析

**方法**:
1. 选择多只相似股票
2. 对比竞价数据
3. 分析相对强弱
4. 选择最优标的

### 5. 风险控制

**基本原则**:
1. 不盲目追高
2. 分散投资，控制仓位
3. 设置止损点
4. 避免满仓操作

**告警辅助风控**:
```
设置负面告警:
- 涨幅 <= -5%（大幅下跌）
- 封单金额突降（资金撤离）
```
