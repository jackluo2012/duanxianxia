## 问题诊断

### 初始症状
- 数据已有 **70+ 小时未更新**（最新数据时间戳：2026-02-06 15:00）
- data-collector 服务运行但无法采集新数据
- kline-collector 等待数据但无新数据写入

### 根本原因
**TDX (通达信) 数据源连接断开**
- 错误：`TDX error: Broken pipe (os error 32)`
- 原因：TCP 连接池中的连接已断开，需要重新建立连接
- 重试机制：虽然代码有重试逻辑，但已断开的连接无法自动恢复

## 技术细节

### TDX 连接池配置

**文件**: `services/data-collector/src/adapters/secondary/tdx_data_source.rs`

**配置**:
- 池大小: 3 个 TCP 连接
- 负载均衡: Round-Robin 轮询
- 重试机制: 3次重试，每次间隔2秒
- 超时时间: 默认 TCP 超时

**环境变量**:
```bash
TDX_POOL_SIZE=3              # TDX连接池大小
COLLECTION_INTERVAL_SECS=5   # 采集间隔（秒）
CLICKHOUSE_URL=http://localhost:8123
```
