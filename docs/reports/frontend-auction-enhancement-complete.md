## 📝 使用说明

### 查看竞价排行

1. 访问 `/auction` 页面
2. 选择排行类型 (买封/强度/涨幅/异动)
3. 查看排行榜列表
4. 点击股票查看详情

### 查看股票详情

1. 在排行榜中点击股票
2. 右侧显示详情面板
3. 查看竞价走势图
4. 查看封单分布
5. 查看详细数据

### 手动刷新

- 点击"刷新"按钮立即更新数据
- 数据每5秒自动刷新
