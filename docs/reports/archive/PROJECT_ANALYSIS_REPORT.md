## 🔍 问题发现与修复

### 问题 1: PostgreSQL 端口冲突

**问题描述**:
```
Error: Bind for 0.0.0.0:5432 failed: port is already allocated
```

**根本原因**: 系统已存在其他 PostgreSQL 容器(`dev-postgres`)占用 5432 端口

**影响**: 阻止数据库服务启动,导致整个系统无法部署

**解决方案**:
1. 修改 `docker-compose.yml` 中 PostgreSQL 端口映射: `5432:5432` → `5433:5432`
2. 更新相关配置和文档说明

**验证结果**: ✅ 数据库成功启动,服务正常

**文件修改**:
- `/home/jackluo/data/duanxianxia/docker-compose.yml:24`

---

### 问题 2: ClickHouse 多条 SQL 执行失败

**问题描述**:
```
Code: 62. DB::Exception: Syntax error (Multi-statements are not allowed)
```

**根本原因**: ClickHouse 默认不支持一次执行多条 SQL 语句,而 `auction.sql` 包含多条 CREATE TABLE 语句

**影响**: 竞价分析表无法初始化,竞价功能无法使用

**解决方案**:
1. 在 SQL 执行时添加 `--multiquery` 参数
2. 更新 `start-all.sh` 脚本使用正确的执行方式

**验证结果**: ✅ 竞价表成功创建(auction_quotes, auction_analysis)

**文件修改**:
- `/home/jackluo/data/duanxianxia/start-all.sh:33`

---

### 问题 3: PostgreSQL 表创建失败

**问题描述**: SQL 文件执行后表未创建成功

**根本原因**: heredoc 格式和特殊字符转义问题

**解决方案**: 改为直接执行单条 SQL 语句,避免 shell 转义问题

**验证结果**: ✅ users 和 user_watchlist 表成功创建,测试用户插入成功

**文件修改**:
- `/home/jackluo/data/duanxianxia/start-all.sh:41-43`
