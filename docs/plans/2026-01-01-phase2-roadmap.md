## 🎯 **Phase 2 目标**

### 2.1 竞价分析模块

**核心功能：**
1. **集合竞价数据采集**
   - 采集9:15-9:25竞价期间数据
   - 记录竞价价格、成交量变化
   - 存储到ClickHouse竞价表

2. **竞价封单分析**
   - 计算竞价封单金额（买一/卖一）
   - 封单涨幅排行
   - 竞价抢筹程度评分

3. **竞价强度指标**
   - 竞价成交金额排名
   - 竞价换手率排名
   - 竞价价格波动分析

**技术实现：**
- 新增 `auction-service` 服务
- ClickHouse竞价表设计
- 前端竞价排行页面

### 2.2 数据挖掘模块

**核心功能：**
1. **个股挖掘**
   - 龙头高度计算（行业龙头分析）
   - 连板天统计（连涨/连跌天数）
   - 涨停跌停分析

2. **概念检索**
   - 概念板块股票列表
   - 板块内个股表现排行
   - 板块资金流向

3. **技术指标计算**
   - MA（移动平均线）
   - MACD
   - KDJ
   - RSI

**技术实现：**
- 扩展 `query-service` 服务
- ClickHouse技术指标视图
- 前端挖掘分析页面

### 2.3 复盘模块

**核心功能：**
1. **每日复盘**
   - 当日涨停股票统计
   - 涨停原因分析
   - 板块热点分布

2. **板块轮动分析**
   - 板块涨跌幅排行
   - 资金流入流出统计
   - 板块轮动趋势图

3. **历史回测**
   - 策略回测框架
   - 收益曲线展示
   - 策略对比分析

**技术实现：**
- 新增 `backtest-service` 服务
- 复盘数据定时任务
- 前端复盘页面

### 数据库扩展

**ClickHouse新表：**
```sql
-- 竞价数据表
CREATE TABLE auction_quotes (
    date Date,
    code String,
    time DateTime,
    price Float64,
    volume UInt64,
    buy_amount Float64,   -- 买封金额
    sell_amount Float64    -- 卖封金额
) ENGINE = MergeTree()
PARTITION BY date
ORDER BY (code, time);

-- 技术指标表
CREATE TABLE stock_indicators (
    date Date,
    code String,
    ma5 Float64,
    ma10 Float64,
    ma20 Float64,
    macd Float64,
    dif Float64,
    dea Float64,
    rsi Float64
) ENGINE = MergeTree()
PARTITION BY date
ORDER BY (code, date);
```
