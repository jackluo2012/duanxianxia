## 🔍 技术细节

### rustdx API 使用

**周期映射验证:**
```rust
KlinePeriod::OneDay => category = 9 ✅

// rustdx category 定义:
// 0=5分钟, 1=15分钟, 2=30分钟, 3=1小时, 9=日线
```

**Kline请求参数:**
```rust
Kline::new(
    market,      // 0=深市, 1=沪市
    code,        // "000001" 或 "600036"
    category,    // 9 (日线)
    start,       // 0 (从最新开始)
    count        // 800 (最大值)
)
```

**生命周期处理:**
```rust
// 正确避免了借用问题
let result: Vec<(NaiveDate, u16, u16, String, f64, f64, ...)> =
    kline_req.data.iter().map(|k| {
        (k.dt, k.dt.hour, k.dt.minute, k.code.to_string(), ...)
    }).collect();
```
